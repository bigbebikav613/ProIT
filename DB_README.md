# Хранение данных

Приложение использует SQLite на сервере. Файл `proit_admin_data.sql` содержит схему и начальные данные, а не рабочее хранилище: после запуска изменения записываются в `proit_admin_data.db`.

В базе находятся:

- `site_content` — контент лендинга, который редактируется в админ-панели;
- `applications` — заявки из публичных форм;
- `admin_credentials` — хеш пароля администратора;
- `rate_limits` — серверные счетчики защиты от перебора и спама.

Заявки шифруются на сервере перед записью в SQLite. Ключ `PROIT_DATA_ENCRYPTION_KEY` не попадает в браузер и не должен храниться в Git.

## Локальный запуск

```powershell
py -3 -m venv .venv
.\\.venv\\Scripts\\python.exe -m pip install -r requirements.txt
$env:PROIT_HTTPS_ONLY = "0"
.\\.venv\\Scripts\\python.exe api_server.py
```

Откройте `http://127.0.0.1:8000/`. При первом входе в `/admin` задайте пароль администратора.

## Ручная инициализация SQLite

Если нужно создать новую базу заранее:

```powershell
sqlite3 proit_admin_data.db ".read proit_admin_data.sql"
```

Если утилита `sqlite3` не установлена, приложение само создаст схему и загрузит seed при первом запуске.

Не редактируйте `.db` вручную во время работы приложения. Для резервной копии остановите контейнер и скопируйте каталог `data/` целиком, включая файлы `-wal` и `-shm`, если они существуют.
